🛡️ Security & Defensive Engineering

Multi-Layer Security & Role-Based Access Control

Zero-trust authorization ensuring strict integrity of institutional syllabus and notes.

Role-Based Access Control (RBAC)

Never trust client-side state. Every modifying HTTP endpoint (POST, PUT, DELETE) verifies signed JWT claims:

• Student: Read-only access, bookmarking, in-browser PDF viewing, career skill mapping. Upload/edit actions blocked for data protection.
• Faculty: Authorized to upload & edit lecture notes, model papers, and suggest projects.
• Admin: Full institutional control, curriculum CRUD, user role management, and database synchronization.

Production Security Measures

🔒 Helmet CSP Headers: Prevents clickjacking, iframe injection, and cross-site scripting.
⏱️ Rate Limiting: 500 req/15min general limiter; 20 attempts/15min brute-force auth limiter.
🛡️ Input Sanitization: Express-validator sanitization preventing NoSQL injection.
🔄 Live Real-time Sync: Admin updates immediately reflected across student sessions without reload.
